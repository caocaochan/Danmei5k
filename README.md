# Danmei 5k

An Anki deck of the 5000 most common words in danmei novels, for learners who want to read them in Chinese.

- **Words** come from a frequency list built from about 2000 danmei novels. Character names are left out.
- **Every card has an example sentence** taken from the novels. Almost all are i+1: the only new word is the one being learned.
- **Definitions** come from CC-CEDICT. Words CEDICT doesn't have, or senses it misses, get definitions written in the same style.
- **TTS Audio** for each word and sentence.
- Uses the [Lapis Chinese](https://github.com/caocaochan/LapisChinese) note type. New cards come in frequency order.

## Download

Get `Danmei5k.apkg` from [Releases](https://github.com/caocaochan/Danmei5k/releases/latest) and open it with Anki (File → Import). Importing a newer version updates your cards in place and keeps your review history.

## Feedback

Please [open an issue](https://github.com/caocaochan/Danmei5k/issues/new) for anything at all, for example:

- a wrong reading or definition
- a sentence that's confusing, garbled, or uses the word in an unusual way
- ideas for the deck

Including the word (or its frequency number) makes it easy to find the card.
